# 🌍 ZounaLa (走哪啦) · 커뮤니티 다국어 로컬라이제이션 프로젝트

> **더 자연스럽고 알맞은 한국어 표현 개선에 참여하고 ‘Ultimate 평생 회원’을 무료로 받아가세요!** 🎁

---

## 📱 프로젝트 소개

![ZounaLa 다국어 화면 비교](localization.png)

**ZounaLa (走哪啦)**는 완전한 프라이버시 보호와 제로 서버 아키텍처를 추구하는 iOS 일상 발자국 및 라이프 모먼트 기록 앱입니다. 산책자, 여행자, 야외 탐험가 및 추억 수집가를 위해 일상의 발자취, 멍때리는 시간(발대/Idle Time), 소중한 사람과의 프라이빗한 순간을 따뜻하게 담아냅니다.

전 세계 사용자에게 가장 자연스럽고 완성도 높은 경험을 제공하기 위해, 앱 내 버튼, 부제목, 알림 문구, 위젯 등 모든 텍스트를 **한국어 (한국어)**, **일본어 (日本語)**, **영어 (English)** 환경에서 더욱 생생하고 매끄럽게 다듬고자 합니다.

---

## 🎯 참여가 필요한 이유

자동 번역은 기본적인 의미를 전달할 수 있지만, 현지의 문화적 맥락과 감성, 자연스러운 어조는 원어민만이 완성할 수 있습니다:

- **한국어에 알맞은 자연스러운 표현**: ‘멍때리기 시간(발대)’, ‘발자국 체크인’, ‘친밀 공간’ 등 ZounaLa만의 고유한 기능을 한국 사용자가 직관적이고 친근하게 느낄 수 있는 어휘 선택.
- **모바일 화면에 최적화된 간결성**: 스마트폰 버튼, 잠금화면 위젯, 알림 팝업에 줄바꿈 없이 깔끔하게 들어맞는 문장 정제.
- **명확한 권한 안내**: 카메라, 사진 보관함, 위치 서비스, 블루투스 등의 시스템 권한 안내를 정중하고 명확하게 전달.

## 🎁 기여자 혜택: ‘Ultimate 평생 회원’ 무료 증정

정성 어린 번역과 개선 제안에 진심으로 감사드리는 마음을 담아:

✨ **Pull Request(또는 가치 있는 번역 개선안)가 검토 후 병합(Approval & Merge)된 모든 기여자분께 앱 내 모든 프리미엄 기능을 영구적으로 이용할 수 있는 ‘Ultimate 평생 회원($24.99+ 상당)’ 활성화 코드를 무료로 증정합니다!**

### 🔑 활성화 코드 수령 방법:
1. **나의 계정 ID 확인**:
   - iPhone에서 **ZounaLa** 앱을 실행합니다;
   - **설정 (Settings)** ➔ **Ultimate 회원 활성화 (Ultimate Membership)** 로 이동합니다;
   - 화면에 표시된 **8자리 계정 ID (Your Account ID)**(예: `886333C5`)를 탭하여 복사합니다.
2. **PR / 커밋에 정보 기재**:
   - Pull Request 생성 시, **PR 설명란**(또는 커밋 메시지)에 아래 내용을 포함해 주세요:
     - **8자리 계정 ID**: (예: `Account ID: 886333C5`)
     - **수신용 이메일 주소**: (예: `Email: yourname@example.com`)
3. **이메일로 코드 수령**:
   - 팀의 검토 및 승인(Approval)이 완료되면, 개별 맞춤형 Ultimate 평생 활성화 코드를 발급하여 기재해주신 이메일로 전송해 드립니다!

## 📂 수정 대상 파일

본 프로젝트에서 수정하는 메인 파일:

- [`Localizable.xcstrings`](Localizable.xcstrings) — Apple 표준 **Xcode String Catalog**(JSON 포맷). **한국어 (`ko`)**, **일본어 (`ja`)**, **영어 (`en`)**, **중국어 간체 (`zh-Hans`)**의 전체 UI 문구가 포함되어 있습니다.

## 🛠 기여 방법

### 방법 1: Xcode 사용 (iOS 개발자 권장)
1. 본 저장소를 Fork한 후 로컬로 Clone합니다;
2. **Xcode 15 이상**에서 [`Localizable.xcstrings`](Localizable.xcstrings) 파일을 엽니다;
3. Xcode의 시각적 String Catalog 에디터에서 미번역 또는 수정이 필요한 항목을 편집하고 저장합니다;
4. 커밋 후 Pull Request를 제출합니다.

### 방법 2: 텍스트/코드 에디터 사용 (VS Code, Cursor, Sublime 등)
1. 본 저장소를 Fork한 후 Clone합니다;
2. 선호하는 에디터로 [`Localizable.xcstrings`](Localizable.xcstrings) 파일을 엽니다;
3. 대상 문구 항목 아래의 언어 키(`"ko"`, `"ja"`, `"en"` 등)를 찾아 `"value"` 값을 수정합니다;
4. JSON 문법에 오류가 없는지 확인합니다;
5. 커밋 후 Pull Request를 제출합니다.

### 방법 3: GitHub Issue로 제안
Git이나 PR 작성이 번거로우신 경우:
1. [GitHub Issues](https://github.com/zouna-la/localization/issues)에서 새로운 Issue를 생성합니다;
2. 수정이 필요한 원문(중국어/영어 키)과 추천하는 한국어 번역을 작성해 주세요;
3. 리워드 수령을 위해 **계정 ID**와 **이메일 주소**를 함께 남겨주세요!

## 💡 번역 가이드라인

- **포맷 지정자 유지**: 동적 숫자나 날짜가 올바르게 렌더링될 수 있도록 `%@`, `%lld`, `%1$@`, `%2$@`, `%d` 등의 변수 기호는 그대로 유지해 주세요.
- **간결한 표현 권장**: 모바일 화면 공간은 제한적입니다. 의미를 정확히 담되, 직역으로 인해 문장이 과도하게 길어지지 않도록 간결하게 다듬어 주세요.
- **따뜻하고 친근한 어조**: ZounaLa는 사용자의 일상을 따뜻하게 기록하는 라이프스타일 앱입니다. 부드럽고 정중하며 긍정적인 문체를 권장합니다.
